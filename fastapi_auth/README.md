# سرویس لاگین ناهمگام پایتون (FastAPI) برای مودل ۴٫۵ بیتنامی

این سرویس یک میکروسرویس مستقل و با کارایی بالا (High-Performance Async) به زبان پایتون (FastAPI) است که برای حل مشکل ترافیک پیک و افزایش ظرفیت همزمانی (Concurrency) در لحظات ورود دانشجوها طراحی شده است.

---

## قابلیت‌ها و ویژگی‌های کلیدی

1. **ورود با نام‌کاربری و پسورد:**
   * اعتبارسنجی ناهمگام هش پسورد (Bcrypt) سازگار با مودل.
   * پشتیبانی از نام‌کاربری، شماره دانشجویی، ایمیل و کد ملی.
2. **ورود با پنجره واحد خدمات دولت من / وزارت علوم (USW OAuth2):**
   * پیاده‌سازی کاملاً Async I/O با `httpx` (جلوگیری از قفل شدن ورکرها در زمان کندی سرورهای دولتی).
   * ایجاد یا تطبیق خودکار کاربر بر اساس کد ملی.
3. **فراموشی رمز عبور (Forgot Password):**
   * صدور توکن امن بازیابی رمز عبور.
   * ارسال ناهمگام ایمیل از طریق Background Tasks (بدون معطل کردن کاربر).
   * امکان تعیین رمز جدید و به‌روزرسانی مستقیم در دیتابیس مودل.
4. **پل امن SSO به مودل (Single Sign-On):**
   * صدور تیکت یک‌بارمصرف امن (HMAC-SHA256 JWT) با اعتبار ۶۰ ثانیه‌ای.
   * تحویل سشن در فایل سبک `auth/sadaa/sso.php` در مودل بدون نیاز به پکیج‌های اضافی در PHP.
5. **طراحی زیبا، ریسپانسیو و کاملاً فارسی (RTL):**
   * رابط کاربری مدرن با پیش‌نمایش خطاها و لودینگ‌های پویا (Fetch AJAX).

## ساختار پروژه

```text
fastapi_auth/
├── app/
│   ├── config.py             # مدیریت تنظیمات (.env)
│   ├── database.py           # استخر اتصالات ناهمگام دیتابیس (aiomysql)
│   ├── security.py           # تولید و اعتبارسنجی JWT و توابع Bcrypt
│   ├── models.py             # مدل‌های Pydantic درخواست‌ها
│   ├── services/
│   │   ├── auth_service.py   # منطق جستجوی کاربر و تغییر رمز
│   │   ├── usw_service.py    # ارتباط ناهمگام با سرورهای دولت من (USW)
│   │   └── email_service.py  # ارسال ناهمگام ایمیل بازیابی
│   ├── routers/
│   │   ├── auth.py           # اندپوینت‌های لاگین، فراموشی و تغییر پسورد
│   │   ├── usw.py            # جریان OAuth2 ورود با USW
│   │   └── views.py          # رندرهای قالب‌های HTML
│   ├── templates/            # قالب‌های Jinja2 به زبان فارسی
│   └── static/               # استایل‌ها و اسکریپت‌های کلاینت
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
└── .env.example
```

## راه‌اندازی و اجرا

### روش اول: اجرا با Docker Compose (پیشنهادی)

1. یک کپی از فایل نمونه تنظیمات بسازید:
   ```bash
   cp .env.example .env
   nano .env
   ```
2. مقادیر مربوط به دیتابیس مودل و USW و کلید SSO را وارد کنید.
3. سرویس را با داکر اجرا نمایید:
   ```bash
   docker compose up -d --build
   ```

### روش دوم: اجرای مستقیم با Python

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

## تنظیمات در پنل مدیریت مودل (Site Administration)

1. فایل‌های به‌روزرسانی شده پلاگین `auth/sadaa` را در پوشه مودل کپی کنید:
   ```bash
   sudo cp -r auth/sadaa /opt/bitnami/moodle/auth/
   sudo chown -R bitnami:daemon /opt/bitnami/moodle/auth/sadaa
   ```
2. وارد پنل مدیریت مودل شوید:
   * **مدیریت سایت ← پلاگین‌ها ← احراز هویت ← Sadaa login**
   * در بخش **FastAPI Auth Service**:
     * **آدرس سرویس FastAPI:** آدرس سرویس لاگین (مثلاً `https://auth.youruniversity.ac.ir` یا `http://localhost:8000`)
     * **کلید امنیتی مشترک (SSO Secret):** دقیقاً همان کلیدی که در فایل `.env` متغیر `SSO_SECRET` قرار داده‌اید.
3. اکنون هر کاربری که وارد صفحه ورود شود، به سرویس سریع پایتون هدایت شده و پس از تأیید، بدون مکث وارد سامانه مودل خواهد شد.
